# PropNest Backend — Beta Roadmap

The backend GitHub issue set is the source of truth for this repository's product-phase sequencing.

## Phase 1

- Collections — done
- complete Payments — done
- Notifications abstraction — outstanding
- Audit Logs — outstanding

## Phase 2

- Lease
- Recurring Billing
- Payment ↔ Billing
- immutable Receipts
- Landlord Dashboard

## Internal Alpha

After Phase 2, use the system with the family's actual rental properties for 2–3 months.

No major new features during the validation window.

## Later phases

- Owner
- Tenant
- Maintenance
- Leasing
- Agent
- Accounting
- Mosaic AI
- third-party integrations

## Architectural direction

The roadmap also proposes eventual migration from flat entity modules to business-capability modules.

See the individual phase documents and `roadmap-alignment.md` for implementation implications.
